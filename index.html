POWERSHELL & CMD DIAGNOSTICS

Diagnóstico Completo de Redes Sem Fio no Windows

Este documento compila a resolução de erros de serviços de rede sem fio, tabelas de referência rápida de comandos `netsh` e `PowerShell`, além de testes avançados de oscilação e manutenção de adaptadores Wi-Fi.

01

Resolução do Erro Inicial: Serviço WlanSvc Parado

Mensagem de Erro Observada: 

PS C:\> netsh wlan show networks mode=bssid
O Serviço de Configuração Automática sem Fio (wlansvc) não está em execução.

O utilitário `netsh wlan` depende diretamente do serviço **WlanSvc (Configuração Automática Sem Fio)** do Windows. Se ele estiver desativado ou parado, a placa Wi-Fi não escaneará nem exibirá nenhuma rede ou BSSID.

Passo a Passo para Correção:

PASSO 1 Requisito de Elevação

Abrir o PowerShell como Administrador

Pressione o menu Iniciar, digite PowerShell, clique com o botão direito e selecione Executar como Administrador.

PASSO 2 Inicialização Imediata

Iniciar o Serviço WlanSvc

Start-Service WlanSvc
PASSO 3 Persistência na Inicialização

Configurar para Início Automático com o Windows

Set-Service WlanSvc -StartupType Automatic
PASSO 4 Validação

Executar Novamente o Comando Desejado

netsh wlan show networks mode=bssid
02

Guia de Comandos para Análise de Wi-Fi e Rede

Comando Tipo Finalidade / Descrição Ação
netsh wlan show networks mode=bssid CMD / PS Exibe todas as redes Wi-Fi ao alcance com sinal, segurança e endereço MAC (BSSID) dos roteadores.
netsh wlan show interfaces CMD / PS Mostra o status detalhado da conexão Wi-Fi atual (qualidade do sinal %, frequência GHz, taxa de transmissão).
netsh wlan show drivers CMD / PS Exibe fornecedor, versão do driver e suporte a recursos avançados (como rede hospedada e Wi-Fi Direct).
netsh wlan show profiles CMD / PS Lista o histórico de todas as redes Wi-Fi às quais o computador já se conectou.
netsh wlan show profile name="NOME" key=clear CMD / PS Exibe as propriedades da rede salva e revela a senha em texto puro no campo "Conteúdo da Chave".
netsh wlan show wlanreport CMD / PS Gera um relatório completo em arquivo HTML contendo histórico de quedas, conexões e desconexões.
Get-Service WlanSvc PowerShell Verifica o status atual (Running/Stopped) do serviço de rede sem fio.
Restart-Service WlanSvc PowerShell Reinicia o serviço de Wi-Fi do Windows para destravar o adaptador sem precisar reiniciar o sistema.
ipconfig /all CMD / PS Lista detalhadamente todos os IPs locais, Gateway Padrão, servidores DNS e MAC de cada adaptador.
ipconfig /flushdns CMD / PS Limpa a memória cache DNS do computador para solucionar falhas na resolução de nomes de sites.
netsh wlan show all CMD / PS Dump completo de todas as informações de WLAN (interfaces, perfis, drivers, redes e políticas).
Get-NetAdapter PowerShell Lista todos os adaptadores de rede físicos e virtuais com status, velocidade de link e interface.
Test-NetConnection 8.8.8.8 -Port 53 PowerShell Teste avançado de conectividade TCP/ICMP, verificando se portas específicas estão acessíveis.
netstat -ano CMD / PS Exibe todas as conexões TCP/UDP ativas e o PID (ID do processo) que está utilizando a porta.
arp -a CMD / PS Mostra a tabela ARP com o mapeamento entre os endereços IP e os endereços MAC da rede local.
nslookup google.com CMD / PS Consulta servidores DNS para verificar falhas de resolução de nomes e endereços IP de domínios.
03

Como Gerar e Analisar o Relatório WLAN Report

O WLAN Report é uma das ferramentas mais valiosas nativas do Windows para diagnosticar quedas intermitentes, falhas de autenticação e problemas de driver Wi-Fi. 

netsh wlan show wlanreport

Onde encontrar o arquivo retornado?

C:\ProgramData\Microsoft\Windows\WlanReport\wlan-report-latest.html

Basta copiar o caminho gerado pelo terminal e colar na barra de endereços do seu navegador (Microsoft Edge, Chrome ou Firefox) para visualizar os gráficos interativos de eventos de rede.

04

Análise de Frequência e Escolha do Canal Wi-Fi

A interferência de roteadores vizinhos operando no mesmo canal causa perda de pacotes e alta latência. Ao rodar o comando abaixo, avalie a distribuição dos canais ao seu redor: 

netsh wlan show networks mode=bssid

Banda de 2.4 GHz

Possui apenas 3 canais que não se sobrepõem: 1, 6 e 11. Se a maioria dos vizinhos estiver usando o canal 6, configure manualmente seu roteador para o canal 1 ou 11.

Banda de 5 GHz / 6 GHz

Possui dezenas de canais independentes (ex: 36, 40, 44, 149). Sofre muito menos interferência, embora tenha um alcance de sinal menor em comparação com a banda 2.4 GHz.

05

Reset Completo da Pilha de Rede (TCP/IP & Winsock)

Quando o Wi-Fi conecta mas fica "Sem Acesso à Internet" ou apresentando erros frequentes de DNS, execute esta sequência completa de limpeza no terminal como Administrador: 

# 1. Liberar e renovar o endereço IP atribuído pelo DHCP
ipconfig /release
ipconfig /renew

# 2. Limpar o cache do resolvedor de nomes DNS
ipconfig /flushdns

# 3. Resetar o catálogo Winsock e a pilha IPv4 / IPv6 aos padrões de fábrica
netsh winsock reset
netsh int ip reset
Nota: Após a execução do `netsh winsock reset`, é essencial reiniciar o computador para concluir o processo de restauração dos drivers de soquete.
06

Teste Avançado de Ping com Timestamp e Registro em Arquivo

Para registrar microquedas ou provar instabilidades para o suporte do seu Provedor de Internet (ISP), este script em PowerShell monitora pings contínuos e anexa a data e hora exatas de cada resposta em um log na sua Área de Trabalho: 

ping -t 8.8.8.8 | ForEach-Object { "$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss') - $_" } | Out-File -FilePath "$env:USERPROFILE\Desktop\ping_log.txt" -Encoding utf8

Como Funciona este Comando:

  • ping -t 8.8.8.8: Dispara pacotes ICMP contínuos para o servidor DNS do Google.
  • ForEach-Object: Captura cada linha retornada pelo ping e adiciona o carimbo de data/hora atual.
  • Out-File ... ping_log.txt: Salva tudo em tempo real em um arquivo chamado ping_log.txt na sua Área de Trabalho.

Pressione Ctrl + C para parar o monitoramento a qualquer momento.

07

Reinstalação Limpa do Driver de Wi-Fi

Se a placa de rede congelar ou parar de responder completamente, reinstalar o driver via Gerenciador de Dispositivos restaura a comunicação do hardware:

  1. Pressione Win + X e selecione Gerenciador de Dispositivos (ou execute devmgmt.msc).
  2. Expanda a categoria Adaptadores de Rede.
  3. Clique com o botão direito na sua placa Wi-Fi (ex: Intel Wi-Fi 6, Realtek Wireless, MediaTek) e escolha Desinstalar o dispositivo.
  4. Marque a caixa "Tentar remover o driver deste dispositivo" e confirme a desinstalação.
  5. Reinicie o computador. O Windows detectará o hardware ao inicializar e instalará automaticamente um driver limpo e operacional.
08

Comandos Avançados Adicionais para Diagnóstico de Rede

Ferramentas adicionais essenciais para auditar portas, tabelas de roteamento, mapeamento de IP/MAC e status de adaptadores no Windows.

Teste de Conectividade com Test-NetConnection

Verifica latência e acessibilidade a uma porta TCP específica (ex: porta 53 para DNS):

Test-NetConnection 8.8.8.8 -Port 53 -InformationLevel Detailed

Auditoria de Portas com Netstat

Exibe conexões ativas junto com o ID numérico do processo (PID):

netstat -ano

Mapeamento Local com Tabela ARP

Lista dispositivos conectados na sua rede local e seus endereços físicos MAC:

arp -a

Consulta de IPs e Rotas via PowerShell

Exibe endereços IP atribuídos e rotas ativas do sistema:

Get-NetIPAddress -AddressFamily IPv4 | Format-Table
Get-NetRoute -AddressFamily IPv4
