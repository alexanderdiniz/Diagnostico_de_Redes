Ordem Lógica para Resolver Falhas de Rede

Siga estas 5 etapas na sequência abaixo para descobrir exatamente onde a conexão está falhando. Clique no comando para copiar.

Passo 1 • Placa de Rede Local

Testa se o protocolo TCP/IP do próprio computador está funcionando.

Passo 2 • Endereço IP e Gateway

Verifica se a máquina recebeu IP válido e qual é o IP do roteador (Gateway).

Passo 3 • Acesso à Internet (por IP)

Testa a saída para a internet sem depender de nomes de sites (DNS).

Passo 4 • Resolução de Nomes (DNS)

Se o Passo 3 funcionou mas sites não abrem, o problema está no DNS.

Passo 5 • Porta e Firewall

Confirma se a porta específica do serviço (ex: 443 HTTPS ou 3389 RDP) está liberada.
